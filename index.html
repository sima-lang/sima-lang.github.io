Фитц

открытый проект · MIT

Настольный ИИ-ассистент на PyQt6 с анимированным персонажем Haru (Live2D). Понимает голосовые и текстовые команды, управляет системой Linux, ведёт память и умеет смотреть на экран.

Командывремя, дата, состояние системы, напоминания, погода, открытие приложений
Памятьхранит историю чата, ищет по ней командой «найди в истории»
ПерсонажLive2D-модель Haru с реакцией на речь (lip-sync)
Безопасностьпроверка ссылок, атомарная запись данных, ограниченный доступ к файлам
ИИответы через подключаемое API языковой модели
Открытостьисходный код, тесты, changelog и README на русском и английском
стек: Python · PyQt6 · Live2D · Psutil · OpenCV · Vosk/SpeechRecognition · TTS
идея · архитектура (ядро + DLC) · интеграция · тестирование
